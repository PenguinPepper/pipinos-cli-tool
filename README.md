## What is pipinos?

Onboarding a new developer to a codebase takes hours — reading READMEs, chasing down docs, reverse-engineering architecture from code. pipinos compresses that into seconds.

Point pipinos at any public GitHub repository and it produces three files:

| File | What it contains |
|------|-----------------|
| `pipinos/flashcards.md` | Q&A cards grouped by category — great for spaced repetition |
| `pipinos/diagram.mmd` | A Mermaid.js architecture diagram of dependencies and structure |
| `pipinos/cheatsheet.md` | Install steps, usage examples, dependency tables, common commands |

pipinos is **100% free to run**. It uses the GitHub API and — optionally — free HuggingFace models for AI-powered summaries. No paid services, no credit card, no lock-in.

## Installation

**Requirements:** Node.js 18 or higher.

### Run without installing

```bash
npx pipinos-cli generate --repo owner/repo
```

### Install globally

```bash
npm install -g pipinos-cli
pipinos generate --repo owner/repo
```

### Install from source

```bash
git clone https://github.com/PenguinPepper/pipinos-cli-tool.git
cd pipinos-cli-tool
npm install
node cli.js generate --repo owner/repo
```

## Usage

### Basic

```bash
# Scan any public repo
pipinos generate --repo facebook/react

# Auto-detect repo from your current directory's git remote
cd my-project
pipinos generate
```

### Options

```
pipinos generate [options]

Options:
  -r, --repo <owner/repo>   GitHub repository to scan
  -t, --token <token>       GitHub personal access token (see Rate Limits)
  -b, --branch <branch>     Branch to scan (default: repo's default branch)
  -o, --output <dir>        Output directory (default: ./pipinos)
  --ai                      Enrich output with AI-powered summaries and Q&A cards
  -v, --version             Print version
  -h, --help                Show help
```

### Examples

```bash
# Scan a specific branch
pipinos generate --repo owner/repo --branch develop

# Custom output directory
pipinos generate --repo owner/repo --output ./docs/onboarding

# With AI enrichment (richer summaries and extra Q&A cards)
pipinos generate --repo owner/repo --ai
```

## AI Enrichment (`--ai`)

When you pass `--ai`, pipinos uses [HuggingFace](https://huggingface.co) free-tier models to improve the output:

- **Summaries** — the overview flashcard and cheat sheet intro are rewritten using `facebook/bart-large-cnn`
- **Q&A cards** — additional cards are generated by asking targeted questions using `deepset/roberta-base-squad2`

AI enrichment is **opt-in** and **free**. The models run on HuggingFace's shared inference infrastructure — no GPU or paid account needed.

> Note: Free tier models may take 10–20 seconds to warm up on first use. pipinos handles retries automatically.

## Rate Limits

pipinos uses the GitHub REST API. Without a token you get **60 requests/hour** (unauthenticated). With a token: **5,000 requests/hour**.

For most repos you won't hit the unauthenticated limit. For large repos or frequent use, set a token:

1. Create a token at [github.com/settings/tokens](https://github.com/settings/tokens) — no special scopes needed for public repos
2. Pass it directly: `pipinos generate --repo owner/repo --token ghp_xxx`
3. Or set it in your environment: `export GITHUB_TOKEN=ghp_xxx`

## Output Format

### `flashcards.md`

Cards are grouped by category and formatted for easy reading or import into tools like Anki or Obsidian.

```markdown
## 💡 Concepts

### Card 1

**Q:** What is next.js?

**A:** A React framework for building full-stack web applications...

---
```

### `diagram.mmd`

A [Mermaid.js](https://mermaid.js.org) diagram you can paste into any Mermaid-compatible viewer (GitHub renders these natively in Markdown).

```
graph TD
  next_js["🗂 next.js"]
  next_js --> UI_Frontend["UI / Frontend"]
  UI_Frontend --> react["react"]
  ...
```

### `cheatsheet.md`

A complete developer reference sheet with install steps, usage examples, dependency tables, and file structure overview.

## Tech Stack
