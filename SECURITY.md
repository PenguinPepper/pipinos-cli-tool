# Security Policy

## Supported Versions

Only the latest release line receives security updates.

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |
| < 1.0   | No        |

## Reporting a Vulnerability

Please do not open a public issue for security problems.

Report vulnerabilities privately using GitHub's **Report a vulnerability** button under the repository's Security tab, or by emailing the maintainer at pfachielizabeth@gmail.com.

You should expect an acknowledgement within 3 business days and a fix plan (or a decision that the report does not qualify) within 14 days. We will credit you in the release notes once a fix ships, unless you prefer otherwise.
